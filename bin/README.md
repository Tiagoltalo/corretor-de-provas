# Meu Projeto

Descrição breve do projeto.

## Pré-requisitos

- Java 17+
- Maven 3.8+

## Como executar

```bash
mvn compile exec:java -Dexec.mainClass="br.com.trabalho.corretordeprovas.Main"
```

## Como testar

```bash
mvn test
```

## Estrutura do projeto

```
src/
├── main/
│   ├── java/br/com/trabalho/corretordeprovas/
│   │   ├── Main.java
│   │   ├── model/
│   │   ├── service/
│   │   ├── repository/
│   │   └── exception/
│   └── resources/
└── test/
    └── java/br/com/trabalho/corretordeprovas/service/
```
